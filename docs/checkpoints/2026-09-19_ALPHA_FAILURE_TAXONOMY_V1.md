# Alpha Failure Taxonomy V1

Canonical detail: `2026-09-19_ALPHA_RESEARCH_PROGRAM_CHECKPOINT_V2.md`.

| Code | Meaning | Current examples |
|---|---|---|
| `FAIL_ENGINEERING_CONFORMANCE` | Implementation invalid; do not interpret as alpha failure | early Stage A v1 |
| `BLOCKED_SOURCE_ADMISSION` | Population/PIT/target authority absent | current historical comparison |
| `BLOCKED_PARTIAL_CAPABILITY` | Finite source support is sparse or incomplete | C3 financial bundle |
| `STRUCTURAL_OVERLAP_CAUTION` | Candidate may duplicate an existing mechanism | C1/C4 internal dependence review |
| `ECONOMIC_CAUTION` | Turnover/concentration/capacity proxy needs review | C1 high turnover; C3 concentration |
| `SEMANTIC_SOURCE_INVALID` | Source does not represent the proposed variable | prior margin interpretation |
| `UNTESTED_FAMILY` | No admitted final experiment exists | ownership/free-float/HSC |

Do not collapse blocked, untested, structurally cautious, semantically invalid,
and predictive failure into one label.
