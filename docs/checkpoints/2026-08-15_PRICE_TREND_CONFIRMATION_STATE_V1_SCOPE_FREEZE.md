# Price / Trend / Confirmation State V1 — Scope Freeze

V1 is frozen to deterministic daily H/L/C/Volume state construction and unit
validation.  The following are explicitly deferred:

- Foreign Flow combination / setup eligibility;
- free-float, HSC, ownership concentration, or supply features;
- ranking-model input or model fitting;
- historical alpha/performance evaluation;
- target/outcome access;
- intraday/TradingView inputs;
- Open-derived features;
- scheduler/counter/runtime deployment.

Any one of those requires a separate lane after independent V1 review.
