## Failure taxonomy and negative results

- `FAIL_ENGINEERING_CONFORMANCE`: implementation invalid; do not call it alpha
  failure (example: early Stage-A v1);
- `BLOCKED_SOURCE_ADMISSION`: population/PIT/target authority absent;
- `BLOCKED_PARTIAL_CAPABILITY`: sparse/partial source support (C3);
- `STRUCTURAL_OVERLAP_CAUTION`: possible mechanism duplicate;
- `ECONOMIC_CAUTION`: turnover/concentration/capacity concern;
- `SEMANTIC_SOURCE_INVALID`: source does not represent the proposed variable;
- `UNTESTED_FAMILY`: no admitted final experiment exists.

H-EXC-01, exact additive foreign-flow formulation, semantic margin direction,
same-surface H-LIQ C2 residualization, and provider/source retries that lack a
